My Python Toolkit

Project Description

My Python Toolkit is a beginner-friendly command-line program built with Python. It contains three useful tools: a simple calculator, an even or odd checker, and a name formatter. The program uses a looping menu so users can choose different tools until they decide to quit.

Features

- Simple Calculator: Adds two numbers and displays the result.
- Even or Odd Checker: Determines whether a whole number is even or odd.
- Name Formatter: Converts names into title case and stores them in a list.
- Menu System: Repeats until the user chooses Quit.
- Input Validation: Handles invalid menu choices and invalid number inputs.

Python Concepts Used

- Variables and user input
- "if", "elif", and "else" conditionals
- "while" and "for" - loops
- Lists and the "append()" method
- F-strings
- String methods
- Exception handling with "try" and "except"
- Comments and functions of built-in methods

How to Run the Program

1. Install Python 3 if it is not already installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

python toolkit.py

5. Follow the menu instructions and enter your choice.

Reflection

The hardest part of this project was making the menu repeat after each tool finished. Testing the name formatter helped me understand how loops and lists work together. I learned that the "append()" method can add new items to a list while a program is running. I also learned how conditionals help a program make decisions. Testing invalid inputs taught me the importance of handling errors so the program does not crash. If I had one more week, I would add a to-do list tool and a tool that saves information to a file. This project helped me improve my Python programming and debugging skills.
