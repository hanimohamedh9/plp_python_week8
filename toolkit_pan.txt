MY PYTHON TOOLKIT PLAN

1. TOOLKIT TOOLS

Tool 1: Simple Calculator
This tool will ask the user for two numbers and calculate their sum.

Concepts: input, variables, arithmetic operators, conditionals, and f-strings.

Tool 2: Even or Odd Checker
This tool will ask the user to enter a number and tell them whether it is even or odd.

Concepts: input, variables, conditionals, modulo operator, and f-strings.

Tool 3: Name Formatter
This tool will ask the user to enter their name and display it in title case.

Concepts: input, string methods, variables, and f-strings.
